# API Reference

Base URL (dev): `http://localhost:8000/api`. Interactive docs (auto-generated by
FastAPI from the actual route definitions): `http://localhost:8000/docs`.

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Backend status, device (cpu/cuda), whether the dataset is the synthetic placeholder |
| GET | `/dataset/stats` | Real dataset analyzer report (counts, dimensions, pairing) |
| GET | `/dataset/gallery/{split}?limit=` | Filenames + image URLs for the Dataset Explorer gallery |
| GET | `/models` | Available models, whether each has a trained checkpoint, parameter count, checkpoint size |
| GET | `/models/compare` | Aggregated real metrics per model, for the Model Comparison page |
| POST | `/restore` | Upload an image, run real inference, optionally compute metrics against a dataset ground truth |
| POST | `/evaluate` | Compute PSNR/SSIM/LPIPS/MAE/MSE between two uploaded same-size images |
| GET | `/results?limit=` | Stored restoration results (SQLite) |
| GET | `/experiments?limit=` | Training run history |
| POST | `/experiments` | Launch a real training run (background task) |
| GET | `/analytics/summary` | Dashboard home metrics (avg PSNR/SSIM/LPIPS/inference time, best model) |
| GET | `/analytics/trends?model_name=` | Time series of stored results, for charts |
| GET | `/analytics/training-history/{model}` | Per-epoch train/val loss from the latest training log |
| POST | `/reports/{result_id}` | Generate a PDF inspection report for a stored result |
| GET | `/reports/download/{report_id}` | Download a generated PDF report |

## `POST /restore`

`multipart/form-data`:
- `file` (required) — image to restore
- `model` (optional, default from config) — `unet` or `swinir`
- `ground_truth_split` / `ground_truth_filename` (optional) — if both given and the
  file exists under `<dataset_root>/<split>/clean/<filename>`, real metrics are
  computed against it

Response (`RestoreResponse`):
```json
{
  "result_id": 1,
  "model": "unet",
  "is_trained_checkpoint": true,
  "device": "cpu",
  "input_image_url": "/api/storage/inputs/...",
  "restored_image_url": "/api/storage/restored/...",
  "ground_truth_image_url": "/api/dataset/image/test/clean/test_0000.png",
  "psnr": 20.42, "ssim": 0.50, "lpips": null, "mae": 0.076, "mse": 0.0091,
  "inference_time_seconds": 0.128,
  "note": null
}
```
`note` is non-null when the model has no trained checkpoint (output is from random
weights) or when no ground truth was supplied (metrics are `null`).

## Error handling

- Unknown model name → `400` with a message listing available models.
- `/evaluate` with mismatched image shapes → `400`.
- Missing report/result IDs → `404`.
- Uncaught exceptions surface as FastAPI's standard `500` with a traceback in the
  server log (not exposed to the client in production — see `docs/deployment_windows.md`
  for running with `--reload` off in production).
